 # Ground-Truth Commitment

The detailed Case 01 scenario is intentionally withheld from the public repository while the forensic investigation is in progress.

Before evidence generation begins, the private scenario plan was cryptographically hashed.

## Purpose

Publishing the hash before evidence generation provides a simple integrity commitment.

After the investigation is complete, the private ground-truth scenario can be disclosed and hashed again.

If the resulting SHA-256 value matches the value recorded here, it demonstrates that the documented scenario plan was not modified after the investigation began.

This mechanism is not intended to replicate formal legal evidence handling.

It is used within this educational lab to demonstrate integrity, reproducibility, and separation between planned ground truth and forensic findings.
