# Case 01 - Scenario Overview

## Case ID

DFIR-CASE-001

## Endpoint

**Hostname:** LAB-WIN11-01

**Primary User:** labuser

## Scenario

A controlled Windows endpoint will contain a sequence of intentionally generated user activity.

The purpose of the investigation is to determine what activity occurred using forensic evidence rather than relying on prior knowledge of the simulated scenario.

Potential areas of interest include:

- user activity
- file activity
- browser artefacts
- command-line activity
- removable media
- running processes
- deleted files
- timeline reconstruction

All files and activity used in the simulation are synthetic.

No real victim, organisation, compromised machine, malware campaign, or unauthorised system is involved.

## Investigator Knowledge

The detailed sequence of actions is intentionally excluded from the public investigation documentation.

The investigator should attempt to reconstruct events from forensic artefacts.

After analysis is complete, the resulting timeline and conclusions will be compared against the privately recorded ground truth.
